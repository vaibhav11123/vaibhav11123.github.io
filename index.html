    • try the budget checksimulation · made-up costs

      simulation with made-up costs: no real model calls, no charges, nothing is sent anywhere. with enforcement on, a run is refused once spent plus a hold reaches the budget. the hold is the median cost of the last runs (zero until there are three), so a run can be refused before spend shows $1.00. it follows the check before each run in budget.py and the status rule in budget_hold.py. calls running at the same time, or a failed budget lookup, behave differently.

## Projects (featured)

- [MCP Watchdog](https://github.com/vaibhav11123/mcp-watchdog): VS Code / Cursor extension that independently probes every MCP server you approved each cycle (process state, transport, protocol negotiation, tool discovery, config, auth), shows health in the status bar and names the cause when one goes quiet while the editor still lists its tools. A doctor workflow gives host-specific fixes, verifies recovery ("Verified" on the Overview) and produces redacted incident reports. TypeScript, 182 unit tests, MIT licence, built and maintained by him (113 of the repo's contributions). Works in Cursor, Windsurf, VS Code and VSCodium. Published on Open VSX (https://open-vsx.org/extension/mcp-watchdog/mcp-watchdog) and the VS Code Marketplace. 100+ developers use it; around 4,000 downloads on Open VSX. The site shows one recorded session in two steps, healthy then search-api failing on test servers: it names the cause (the process closed the connection) and reports the editor's own session as unknown. Shows: shipping a developer tool to real users, reliability engineering, product positioning.
- [AgentCOGS](https://github.com/vaibhav11123/agentcogs): open-source Python SDK that tags model calls with a customer id so AI spend, budgets and contribution margin show up per account, so a B2B AI company can see which customers stop making money before the month ends. Captures usage from OpenAI and Anthropic client calls, prices them against a price book, enforces budget caps, and comes with a self-hosted dashboard. On PyPI (https://pypi.org/project/agentcogs/): 1,800+ downloads. Live demo (https://agentcogs.vercel.app/) runs on fictional sample data. The site has a labeled simulation (made-up costs, no real calls) of the budget check: enforcement is off by default; when on, run() raises CustomerBudgetExceededError before the call once spent plus a hold of the typical recent run cost reaches the budget. Shows: SDK design, unit economics, Python packaging and distribution.
- [JAX MoE kernel](https://github.com/vaibhav11123/jax-transformer-vlad): fused mixture-of-experts expert projections in JAX Pallas for a TPU v5e, written as part of Vlad Feinberg's frontier-lab roadmap. Fusing keeps the intermediate on-chip instead of round-tripping through HBM. Measured on TPU v5e, median of 50 runs: full forward 0.432 ms unfused vs 0.396 ms fused (1.09x); projection 0.400 ms vs 0.331 ms (1.21x). Recorded with jax 0.11.2 on a Colab TPU v5e (T=8192 tokens, E=256 experts, bf16, 10 warm-up runs, baseline jax.lax.ragged_dot); the repo's requirements.txt pins jax 0.10.2 for the training code, so the benchmark needs its own 0.11.2 environment. These timings alone do not explain why the saving differs between the two scopes; a profile is needed. To run: python -m moe_pallas.benchmark --kernel both --bt 32 --reuse 1 --figure. Uses synthetic expert assignments, not a learned router. The same repo has a from-scratch digit-addition transformer (about 10.6M parameters, JAX / Flax NNX / Optax, 100% exact match on 512 held-out sums) and Chinchilla-style scaling sweeps, all screen-recorded. Recorded walkthroughs: https://www.youtube.com/playlist?list=PLQHXISqfzAx8 and https://youtu.be/ji2_hHj-UI4 . Shows: accelerator programming, benchmarking discipline, learning in public.
- Wardyn (private repository, client project): LLM governance control plane. He implemented entitlement filtering, policy configuration, session and token accounting, audit-before-response enforcement with HMAC hash-chained logs, and a CI workflow, with a 731-test suite. Shows: backend and security-minded design for enterprise AI.
- RivRank (private repository, B.Tech research project): graph-based ranking over river networks. A directed MixHop ranking model, evaluated on 252 held-out Mekong queries across three seeds, with the recipe selected on two networks and held fixed for confirmation on the remaining ten. Shows: graph ML and careful evaluation.
- Hublet / DISA ([repo](https://github.com/vaibhav11123/Hublet-ALPS), [live](https://hublet-alps.vercel.app)): end-to-end analytics for coworking and office rent prices across Indian cities: scraping (MagicBricks, MyHQ), model training, ResNet-50 features from listing photos, a Flask prediction API with model-drift monitoring, and a Next.js 14 + Firebase front end for users, sellers and admins.
